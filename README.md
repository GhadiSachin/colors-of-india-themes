# Colors of India – VS Code Themes

There are 10 vibrant themes in this collection, each representing the unique colors and culture of an Indian state:
- **Maharashtra – Land of Warriors**
- **Kerala – God's Own Country**
- **Rajasthan – Land of Kings**
- **Tamil Nadu – Temple Land**
- **Punjab – Land of Five Rivers**
- **West Bengal – Cultural Hub**
- **Gujarat – Vibrant Culture**
- **Karnataka – Sandalwood State**
- **Assam – Tea Gardens**
- **Goa – Beach Paradise**

This collection is designed to bring the **rich cultural palette of India** into your editor, using colors inspired by festivals, textiles, landscapes and architecture, while staying highly readable for daily coding and recording sessions

## Installation

### From Marketplace (when published)

1. Open **Visual Studio Code**
2. Go to **Extensions** (`Ctrl+Shift+X` / `Cmd+Shift+X`)
3. Search for **“Colors of India”**
4. Click **Install**
5. Press `Ctrl+K Ctrl+T` (or `Cmd+K Cmd+T` on Mac) and pick your favorite theme

### Manual / VSIX Install

1. Download the `colors-of-india-themes-*.vsix` file  
2. In VS Code, open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`)  
3. Run **“Extensions: Install from VSIX…”**  
4. Select the downloaded `.vsix` file  
5. After install, select a theme from **Color Theme**

---

## Switching Between Themes

- Press `Ctrl+K Ctrl+T` (Windows/Linux) or `Cmd+K Cmd+T` (macOS)  
- Use arrow keys to preview each **Colors of India** theme live  
- Press **Enter** to select the one you like
